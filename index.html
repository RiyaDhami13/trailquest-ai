🥾 TrailQuest AI

An offline-first, local AI outdoor adventure generator built for the Hacktoberfest 2026 Touch Grass Challenge.

📱 Application Demo

Runs locally via Ollama (Google Gemma 2B / Qwen 2.5 3B) and Streamlit with 0% data egress.

💻 Quick Local Run

git clone https://github.com/RiyaDhami13/trailquest-ai.git
pip install -r requirements.txt
streamlit run app.py
